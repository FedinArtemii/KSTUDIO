# KSTUDIO

Главная страница студии колористики по согласованному макету C «Фактура».

- [Локальный WordPress](http://127.0.0.1:8174/)
- [Демонстрация на GitHub Pages](https://fedinartemii.github.io/KSTUDIO/)

## WordPress

На Windows запустите `./scripts/local.ps1` из PowerShell. Нужен PHP с расширениями PDO SQLite, SQLite3, GD и Mbstring. При первом запуске скрипт устанавливает отдельный WordPress с SQLite, активирует тему и создаёт главную. Существующая главная сохраняется при повторном запуске.

Откройте [админку](http://127.0.0.1:8174/wp-admin/) и выберите **Страницы → Главная**. Заголовок, тексты, кнопки, раскрывающиеся ответы и пять фотографий доступны в редакторе блоков. Данные для входа создаются на компьютере и сохраняются в `.local/login.txt`.

## Статическая версия

После сохранения изменений в WordPress выполните из корня:

```powershell
php -c .local/php.ini scripts/export.php
```

Команда обновляет `docs/index.html` и копирует связанные изображения и ресурсы. GitHub Pages публикует каталог `docs` из ветки `main`.

## Фото и движение

Крупный план, референсы оттенков и интерьер взяты из фотобанков для демонстрации. Ссылки на авторов и лицензии находятся на странице «Источники фотографий». KSTUDIO набрано текстом. В демо указаны предоставленные ссылки на запись и сообщество VK.

Кадр первого экрана мягко приближается к рабочему масштабу. В разделе «Оттенки волос» блик проходит по фото одновременно с возвращением контраста и цвета. Раскрывающиеся ответы и мобильное меню используют стандартные элементы браузера. При включённом уменьшении движения цвет, тексты и действия сразу отображаются в конечном состоянии.
